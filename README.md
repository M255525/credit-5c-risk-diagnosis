# 信用 5C 財務風險診斷

站在銀行放款的角度，用**信用 5C**（品格、能力、資本、擔保品、條件）、償債比率與「創業十大避免」評估一家中小企業／農業食品企業「值不值得借錢給它」，並自動產生授信審查意見書。

線上使用：https://m255525.github.io/credit-5c-risk-diagnosis/

- 16 項財務比率＋燈號、5C 雷達圖、A～D 評等與建議核貸額度
- 創業十大避免自動偵測＋手動改判
- 審查意見書列印／PDF／Markdown、AI 深化分析提示詞、課程影片講稿大綱
- 範例公司全為虛構；教學用途，不構成授信或投資建議
